## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Combolands: Roguelike Citybuilder**. This trainer provides optional quality-of-life controls for single-player runs, including Gold adjustments, population support, week management, building-placement assistance, and progression controls. It is designed around the game's real systems: procedural islands, guild pairings, building combos, upgrades, potions, heirlooms, councillors, and increasingly difficult ranks.

**Target Audience:** Single-player players who want to experiment with building combinations, explore guild pairings, test upgrades and potions, reduce run pressure, or speed up progression through the game's citybuilding systems.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Combolands is a mouse-focused strategy game rather than an action game. Use the mouse to inspect the procedural island, review building choices, select placements, and manage run decisions. The trainer does not modify character movement because the game has no traditional player-controlled character movement.

### Tools & Inventory

The game uses run-based selections rather than a conventional character inventory. Heirlooms provide passive modifiers, while upgrades and potions affect buildings or the map. Enable resource or progression options before selecting these systems, then disable them after confirming the desired change.

### World & Environment

Each run begins on a new procedural island. Choose two guilds, review the available building options, and place structures to create useful spatial interactions and cascading combos. Placement assistance and week controls are most useful when planning around limited terrain, future triggers, and population targets.

### Combat & Weapons

Combolands has no traditional combat gameplay. Its main challenges come from turn-based city planning, building synergies, scoring chains, resource decisions, council progression, and rank objectives. Combat-related trainer options are therefore not applicable.
